## 4. Ruang Lingkup UI (M8.3)

Pola yang harus diikuti: React + Vite + Tailwind + ikon Lucide, tanpa emoji; service di `frontend/src/services/*.js` mengikuti pola `accountService.js` (axios instance `api.js` sudah menyertakan token); modal mengikuti pola bottom-sheet di `AccountModal.jsx`/`TransferModal.jsx`; format Rupiah memakai `utils/currency.js`. Tiap berkas halaman/komponen menjaga batas ukuran Coding Standards (halaman ideal di bawah 450 baris; pecah menjadi komponen).

### 4.1 Navigasi
- Rute baru `/import` di `App.jsx` (di dalam `ProtectedLayout`), entri "Import" di `Sidebar.jsx` (ikon `FileUp`/`Upload`).
- **`BottomNav.jsx` sudah penuh (5 item).** Jangan menambah item keenam. Akses mobile lewat tombol "Import Mutasi" di header halaman Transaksi dan Rekening (dan tautan dari Sidebar untuk desktop).

### 4.2 Layanan frontend
`frontend/src/services/importService.js`: `previewImport(formData)` (multipart), `commitImport(id, rows)`, `getImports(params)`, `getImportById(id)`, `rollbackImport(id)`, `downloadTemplate(bank, format)` (axios `responseType: "blob"` dengan header token, lalu unduh via object URL; **bukan** `window.open`, karena endpoint butuh Authorization), dan fungsi category rules (`GET/POST/PUT/DELETE /api/category-rules`) bila dipakai.

### 4.3 Halaman `/import` (dua tab: "Impor Baru" dan "Riwayat")
**Tab Impor Baru** (alur bertahap):
1. **Pilih rekening** (dropdown rekening aktif). Jika respons preview berisi `suggested_account` yang berbeda dari pilihan, tampilkan banner "Gunakan rekening ini" (hanya usulan; user memutuskan). Peringatan nomor rekening tidak cocok tampil di panel peringatan, tidak memblokir.
2. **Pilih berkas**: dropzone `.csv`/`.xlsx`, cek di klien (ekstensi, maksimal 5 MB) sebelum kirim. Pilihan parser: Otomatis (bawaan), Mandiri, Template, Generic.
3. **Menu Template**: tombol "Unduh Template" dengan dropdown bank dan pilihan format (XLSX/CSV). Daftar bank diambil dari backend (lihat M8.3-1) agar tidak menyimpang dari allowlist.
4. **Modal password** muncul bila backend menandai berkas terenkripsi/password salah (lihat M8.3-1, via `errors[].field === "file_password"`, bukan mencocokkan teks pesan). Input `type="password"` dengan `autocomplete="off"`; password hanya hidup di state komponen modal, dikosongkan setelah request (berhasil maupun gagal), tidak pernah disimpan atau dicatat.
5. **Pemetaan kolom Generic** (hanya bila parser Generic dipilih): form kolom `date`, `description`, `amount` atau `debit`+`credit`, `type`, `date_format` (isi nama kolom di baris header). Sertakan tautan "atau gunakan template standar".
6. **Tinjau hasil preview**: bar ringkasan (`total`, `new`, `duplicate`, `invalid`), panel peringatan yang dapat dilipat (peringatan parser, rekonsiliasi saldo, dst.), tabel (desktop) / kartu (mobile < 768px): centang `include` (duplikat tidak tercentang bawaan), dropdown kategori (hanya kategori bertipe sesuai baris), badge duplikat, badge sumber usulan (`suggestion_source`: aturan Anda / bawaan / template / cadangan), kontrol "Ingat aturan ini" (`learn_rule`) dengan keyword yang dapat diedit (nilai awal `suggested_keyword`). Aksi massal: pilih semua baru, kosongkan semua.
7. **Simpan**: kirim `rows: [{ index, category_id, include, learn_rule, keyword }]`; tampilkan hasil (`imported_rows`, `duplicate_rows`, `skipped_rows`, `rules_saved`, `rule_warnings`) dengan tautan ke Transaksi.

**Tab Riwayat:** daftar batch (nama berkas, rekening, parser, status `PREVIEW|COMMITTED|CANCELLED`, jumlah baris, waktu), detail batch, dan **Rollback** (hanya `COMMITTED`) dengan modal konfirmasi yang menjelaskan bahwa transaksi batch dihapus dan saldo kembali.

### 4.4 Persyaratan non-fungsional
- Responsif: uji di lebar 375px, 768px, dan desktop; tidak ada scroll horizontal pada halaman.
- Aksesibilitas dasar: label pada semua input, fokus terlihat, modal dapat ditutup dengan Esc, kontras warna sesuai desain yang ada.
- Semua teks UI Bahasa Indonesia; pesan error ditampilkan dari `response.data.message` (pola yang sudah dipakai).
- Tidak ada penyimpanan data mutasi di localStorage/sessionStorage.
