## Ringkasan Implementasi
Menyelesaikan seluruh peningkatan cerdas dan jalur template standar seragam untuk modul Statement Import (MOD-08):
- **Rate Limit Strict Default**: Batas bawaan 10 request upload per 10 menit di semua environment via `parseRateLimitMax()`, relaksasi hanya lewat env `IMPORT_RATE_LIMIT_MAX`.
- **Usulan Rekening (Suggested Account)**: Evaluasi 4 digit akhir nomor rekening berkas (`meta.accountNumberMasked`) terhadap rekening aktif pengguna. Jika tepat 1 rekening cocok, `suggested_account: { id, name, institution, match: "last4" }`. Peringatan non-blocking jika nomor rekening berkas berbeda dari rekening terpilih.
- **Belajar Aturan (Learn Rule)**:
  - Pratinjau menyertakan kandidat kata kunci (`suggested_keyword`) via `deriveKeyword()`.
  - Pilihan opt-in `learn_rule: true` per baris saat commit menyimpan aturan ke `category_rules` secara atomik di dalam `$transaction` (batas 500 aturan per user, sanitasi awalan formula `= + - @`, pembaruan kata kunci eksisting).
  - Endpoint baru `PUT /api/category-rules/:id` untuk memperbarui `keyword` dan `category_id` dengan validasi integer positif dan penanganan tabrakan `UNIQUE` (HTTP 400).
- **Penyempurnaan Prioritas Kategorisasi**:
  - Prioritas penentuan kategori: (1) Explicit Template Category (`suggestion_source: "template"`), (2) User Rules terpanjang menang (`suggestion_source: "user_rule"`), (3) Built-in Keywords (`suggestion_source: "builtin"`), (4) Fallback ("Lainnya") (`suggestion_source: "fallback"`).
- **Template Standar FinReport**:
  - Modul generator in-memory XLSX & CSV untuk daftar institusi yang didukung: `BCA`, `MANDIRI`, `BRI`, `BNI`, `CIMB`, `JAGO`, `DANA`, `OVO`, `GOPAY`, `LAINNYA`.
  - Sheet `Mutasi` (header dibekukan, validasi dropdown Jenis), sheet `Info` (`FINREPORT-IMPORT-V1`), sheet `Petunjuk`.
  - Endpoint `GET /api/imports/template`.
  - Parser adapter `template` (`parsers/template.js`): deteksi skor 1.0 (info sheet) dan 0.9 (headers), parsing tanggal UTC tanpa pergeseran timezone WIB/UTC, dan pelaporan baris tidak valid pada `summary.invalid`.
- **Suite Pengujian**:
  - `backend/scripts/verify-m8.2.js`: 7 skenario pengujian sintetik komprehensif lulus 100%.
