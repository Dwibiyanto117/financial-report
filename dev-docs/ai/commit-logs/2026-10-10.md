## Ringkasan Implementasi

### Batch M8.3 (Frontend UI & Dukungan Backend)
- **Perbaikan Hasil Review M8.2 (M8.3-0)**:
  - Uji regresi baseline `backend/scripts/verify-m8.2.js` menggunakan saldo hitung (`currentBalance`) dan jumlah transaksi seluruh pengguna non-uji.
  - Skrip uji rate limit terisolasi di `backend/scripts/verify-rate-limit.js` (10 request 200 OK, request 11-12 HTTP 429).
  - Skrip uji invariansi 4 zona waktu `backend/scripts/test-tz-template.js` (UTC, Asia/Jakarta, America/Los_Angeles, Pacific/Kiritimati).
  - Sanitasi pesan galat HTTP 400 allowlist template bank tanpa memantulkan raw user input.
  - Dukungan komponen UTC pada kolom Waktu bertipe objek Date Excel pada `parsers/template.js` serta pelaporan warning format per baris.
- **Dukungan Backend untuk UI (M8.3-1)**:
  - Format galat berkas terenkripsi membawa `error.errors = [{ field: "file_password", message: ... }]` pada `reader.js`.
  - Endpoint allowlist bank `GET /api/imports/template/banks` dari `bankTemplates.js`.
  - Pembatalan batch `PREVIEW` via `DELETE /api/imports/:id` menjadi `CANCELLED` tanpa menghapus transaksi (`deleted_transactions: 0`).
  - Pembersihan malas (*lazy cleanup*) batch `PREVIEW` usang (> 24 jam) saat `POST /api/imports/preview`.
  - Skrip verifikasi mandiri `backend/scripts/verify-m8.3-backend.js` lulus 100%.
- **Layanan Frontend & Kerangka Halaman (M8.3-2)**:
  - Client API HTTP `frontend/src/services/importService.js` (preview, commit, rollback, list, template banks, blob download, category rules).
  - Rute `/import` di `App.jsx`, menu Sidebar desktop, tombol akses cepat di header Transaksi dan Rekening.
- **Form Konfigurasi, Dropzone, & Modals (M8.3-3)**:
  - Dropzone berkas drag-and-drop (.csv/.xlsx maks 5 MB).
  - Modal unduhan template bank dinamis via blob (`TemplateDownloadModal.jsx`).
  - Modal password in-memory zero-logging (`FilePasswordModal.jsx`).
  - Form pemetaan kolom generik kustom (`GenericMappingForm.jsx`).
  - Banner usulan rekening tujuan (`suggested_account`) 1-klik.
- **Tinjau Pratinjau Mutasi & Commit (M8.3-4)**:
  - Bar ringkasan metrik & panel collapsible peringatan (`ImportSummaryBar.jsx`).
  - Tabel desktop (>= 768px, `ImportReviewTable.jsx`) dan kartu mobile (< 768px, `ImportReviewCards.jsx`): aksi massal, checkbox baris, dropdown kategori tipe sama, badge duplikat, badge rekomendasi kategori, badge informasional potensi transfer ("Mungkin Transfer"), kontrol `learn_rule`.
  - Layar hasil commit (`ImportResultScreen.jsx`).
- **Tab Riwayat & Rollback Atomik (M8.3-5)**:
  - Tab riwayat batch (`ImportHistoryList.jsx`) dengan filter rekening & status (`ALL`, `COMMITTED`, `CANCELLED`, `PREVIEW`).
  - Modal konfirmasi rollback atomik pemulihan saldo (`RollbackConfirmModal.jsx`).
- **Polesan Aksesibilitas & Dokumen (M8.3-6)**:
  - Aksesibilitas keyboard (Escape & backdrop close, dropzone tabIndex & Enter/Space, radiogroup parser).
  - Atribut ARIA (`role="dialog"`, `role="tablist"`, `role="tab"`, `aria-selected`, `aria-label`).
  - Integrasi handler submit password berkas `handlePasswordSubmit`.
